# Installation
1. To install a widget, click **Content Hub** > **Discover**.
2. From the list of widgets that appears, search for and select **ROI Calculator** widget.
3. Click the **ROI Calculator** widget card.
4. Click **Install** on the lower part of the screen to begin installation.

# Configuration

> [!NOTE]  
> Add the **ROI Calculator** directly to your dashboard or report. No additional configuration is required.
